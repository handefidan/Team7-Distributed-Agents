# Definition of Done (DoD) - Team 7

A Product Backlog Item (PBI) or task is considered "Done" when it meets the following criteria:

1. **Code Quality & Style:** The code must be clean, modular, and readable, adhering to agreed-upon formatting standards.
2. **Version Control & Git Workflow:**
   - Direct commits to the `main` branch are prohibited.
   - Work must be done in a dedicated feature branch (`feature/...`).
   - A Pull Request (PR) must be submitted and reviewed/approved by at least one team member before merging into `main`.
3. **Functional Verification:**
   - The Master Agent's output must validate cleanly against the JSON schema without errors.
   - The web user interface must render correctly without console or network errors.
4. **Documentation:**
   - Code must include essential docstrings/comments.
   - Changes must be reflected in the project `README.md` and related documentation files.
5. **Scrum Artifact Compliance:**
   - Acceptance criteria defined in the Trello card must be fulfilled.
   - The corresponding Trello card must be moved through "Testing / Review" to "Done".
